PROJECT ANDROID: MyFirstListView

Fitur sesuai instruksi PDF:
- ListView dengan data awal 1 sampai 5
- Tombol Tambah Data menambah angka berikutnya
- Klik satu item menampilkan Toast
- Double-tap item membuka dialog Update / Hapus / Batal
- Update memakai dialog dengan EditText dan tombol Simpan / Batal
- Layout LinearLayout vertikal dengan pembagian weight 9:1

Cara membuka:
1. Ekstrak ZIP.
2. Buka Android Studio.
3. Pilih Open, lalu pilih folder MyFirstListView hasil ekstrak.
4. Tunggu Gradle Sync selesai.
5. Jalankan di emulator atau perangkat Android.

Catatan:
- Package: com.example.myfirstlistview
- MainActivity: app/src/main/java/com/example/myfirstlistview/MainActivity.kt
- Layout: app/src/main/res/layout/activity_main.xml
- Proyek memakai Android Gradle Plugin 8.7.3 dan Kotlin 2.0.21.
